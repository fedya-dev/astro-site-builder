# Changelog

## 1.1.1

- Added an accessible GitHub profile icon/link to the footer of generated sites.
- Reworked the Bulgarian and English READMEs with clearer installation, usage, SEO, validation and deployment instructions.
- Explicitly credited the project as a collaboration between Fedya Serafiev and ChatGPT (OpenAI).
- Added bilingual `CONTRIBUTING.md` guidelines.
- Fixed documentation references and expanded smoke tests.

## 1.1.0

- Replaced Editorial with **Ocean**, a substantially different blue/green design with a light default background, gradients, rounded navigation, buttons and cards.
- Preserved the original Midnight theme.
- Added Bulgarian documentation: `README.md`, `CUSTOMIZATION.md` and `CHANGELOG.md`.
- Retained English documentation in `README.en.md`, `CUSTOMIZATION.en.md` and `CHANGELOG.en.md`.
- Expanded smoke tests for the new design and bilingual docs.

## 1.0.9

- Added the FS monogram to the header and regenerated favicon assets.
- Added a second design preset.
- Localized RSS titles/descriptions and fixed the English footer RSS link.
- Added a practical guide to editing navigation, footer, themes, articles and categories.

## 1.0.8

- Added `BlogPosting` and `WebSite` JSON-LD structured data.
- Added reciprocal `hreflang` links for translated articles and localized RSS discovery.

## 1.0.7

- Added automatic article TOC generation from H2 and H3 headings.

## 1.0.6

- Improved accessibility, mobile navigation, localized messages, article metadata and tag links.

## 1.0.5

- Restricted generation to Blog projects; Portfolio and Hybrid modes were removed.
- Added `public/images/` and sample articles with complete frontmatter.
