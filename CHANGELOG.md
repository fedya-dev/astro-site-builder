# История на промените

## 1.1.1

- Добавена е достъпна икона с връзка към GitHub профила `fedya-dev` във футъра на генерираните сайтове.
- Преработени са README файловете на български и английски с по-пълни инструкции за инсталация, употреба, SEO, проверки и публикуване.

- Добавена е документация на български: `README.md`, `CUSTOMIZATION.md` и `CHANGELOG.md`.

- Разширени са smoke тестовете за новия дизайн и двуезичните документи.
